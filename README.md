# Drone boat 3D viewer (GitHub Pages)

This branch holds only the browser 3D viewer of the Rev E3 boat and its parts, published at
https://sheltonr2.github.io/drone-boat/ . The source lives on `main` in `build-files/viewer/`
(index.html and model.json); this branch is a copy of those two files. Nothing else from the repository is published here.
